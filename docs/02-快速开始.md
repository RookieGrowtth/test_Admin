# 快速开始与部署

## 前置条件

- Docker Desktop 4+（推荐）与 Docker Compose v2。
- 或 Node.js 20+，用于本地开发。

## Docker Compose 部署

在项目根目录执行：

```bash
cp .env.example .env
```

编辑 `.env`，至少修改 `APP_SECRET` 为长度不少于 32 位的随机字符串。随后启动：

```bash
docker compose up -d --build
docker compose ps
```

浏览器访问 `http://服务器地址:8080`。停止服务使用 `docker compose down`；该操作不会删除 `ai-testhub-data` 数据卷。若要在非 8080 端口发布，在 `.env` 设置 `PORT=18080` 后重新启动。

## 本地开发启动

项目仅依赖 `xlsx-js-style`（Excel 导入导出），安装后即可运行：

```bash
npm install
APP_SECRET='local-development-long-secret-change-me' npm start
```

随后访问 `http://localhost:8080`。热更新可使用 `npm run dev`。

## 数据备份与恢复

全部业务数据保存在 SQLite 文件 `data/ai-testhub.db` 中。Docker 部署时该目录位于 Compose 命名卷 `ai-testhub-data`；本地 Node 启动时位于项目目录的 `data/`。升级前先执行：

```bash
docker compose cp ai-testhub:/app/data/ai-testhub.db ./backup-ai-testhub.db
```

恢复时停止服务，将备份文件放回同一路径后再启动。若服务正在运行，请同时备份 WAL 文件或使用 SQLite 在线备份。生产环境建议将数据卷做定期快照，并在高并发/多实例场景迁移到受控 PostgreSQL。

## 生产部署清单

1. 通过 Nginx、Caddy 或云负载均衡提供 HTTPS。
2. 设置强随机 `APP_SECRET`；变更该值将使原加密 AI Key 无法解密，需重新配置。
3. 用防火墙或内网访问控制限制 8080 管理端口。
4. 修改默认账号密码，按需开启用户 2FA。
5. 定期备份数据卷，定期轮换 AI API Key。
