## 项目数据范围

项目经理和测试主管拥有项目管理权限，可维护项目成员。测试工程师与开发工程师可查看加入的项目；访客可查看系统中的项目与报告。生产扩展时，建议将访客范围进一步约束为指定项目成员。

## 2FA

每个用户可在“账号安全”中开启基于 TOTP 的双因素认证。完成绑定后，密码验证成功仍需要输入验证器的 6 位动态码，才会取得 8 小时有效的登录令牌。

## 访问令牌（API Token）范围限制

除浏览器登录会话外，超级管理员可在“访问令牌”创建以 `ath_` 开头的 API Token。令牌只在创建时显示一次，服务端只保存其 SHA-256 摘要。

- `read`：只能读取创建者已有角色权限内、且被令牌授权的项目；不能执行写入、导出、执行或系统管理操作。
- `write`：可在项目范围内创建/修改测试资产和 UI 自动化脚本；不能管理用户、AI 配置或访问令牌。
- `admin`：可使用创建者角色本身允许的管理能力。它不会绕过创建者的角色权限。
- 项目范围：令牌可以绑定一个或多个项目。调用其他项目数据会被服务端拒绝。
- 撤销：管理员撤销后令牌立即失效。

系统同时校验“用户角色权限 + 令牌级别 + 令牌项目范围”；前端按钮隐藏不构成安全边界。

## 密码管理（超级管理员专属）

“用户与权限”页面中的“修改密码”操作仅向超级管理员展示，接口同样强制要求 `user:manage` 权限：

- 超级管理员重置**其他用户**密码时，不需要、也不会要求输入目标用户的原密码；只需设置并确认新密码。
- 超级管理员修改**自己的**密码时，必须先验证当前密码，防止已登录终端被他人直接接管。
- 新密码至少 8 位；前端还会要求两次输入一致。
- 密码变更后，目标用户已有网页登录会话立即失效；下一次请求会收到未授权响应并回到登录页。该用户创建的 API Token 也会被自动撤销，无法继续调用接口。
- 项目经理、测试主管、测试工程师、开发工程师和访客均无密码修改权限，直接调用接口会返回 HTTP `403 forbidden`。
