# AI 智能助手

## 配置步骤

1. 使用超级管理员登录。
2. 打开左侧“AI 设置”，点击“添加模型”。
3. 填写名称、兼容 API 的 Base URL、模型名称和 API Key。
4. 保存后模型会自动成为默认模型；可以编辑其他配置并设为默认。
5. 切换到“AI 智能助手”，选择技能，输入业务内容并生成。

支持 OpenAI Chat Completions 兼容协议。例如：

| 服务 | Base URL 示例 | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |

请以各供应商当前官方文档为准，并确认对应模型已在账号中开通。

## 已提供技能

- 智能用例生成：把需求转换成包含前置条件、步骤、预期结果、优先级的测试用例。
- 缺陷根因分析：基于缺陷现象，输出可能根因、修复建议和验证方案。
- 测试报告摘要：基于当前平台聚合的执行与缺陷数据，输出质量结论和改进建议。

## 密钥安全

API Key 使用由 `APP_SECRET` 派生的 AES-256-GCM 密钥加密保存，读取配置接口只返回“已配置”状态，不会返回原始 Key。务必妥善保存 `APP_SECRET`；更换它会使历史密钥不能解密。生产环境应使用密钥管理服务替代环境变量，并限制管理员权限。
