# AI 智能助手

## 配置步骤

1. 使用超级管理员登录。
2. 打开左侧“AI 设置”，点击“添加模型”。
3. 填写名称、兼容 API 的 Base URL、模型名称和 API Key。
4. 首个模型会成为默认模型；后续模型可在生成页选择为主模型或备用模型。
5. 切换到“AI 智能助手”，选择技能，输入业务内容并生成。

支持 OpenAI Chat Completions 兼容协议。例如：

| 服务 | Base URL 示例 | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |

请以各供应商当前官方文档为准，并确认对应模型已在账号中开通。

## 已提供技能

- 智能用例生成：先把需求拆为带原文引用的需求项，再分批生成用例；本地校验 JSON 结构、步骤/预期对应、需求追溯、需求覆盖与标题重复，必要时进行一次定向修复。质量门禁未通过时不会提供可保存结果。
- 缺陷根因分析：基于缺陷现象，输出可能根因、修复建议和验证方案。
- 测试报告摘要：基于当前平台聚合的执行与缺陷数据，输出质量结论和改进建议。

智能用例生成页面现在通过 `vendor/testcase-engine/TestCaseGeneratorEngine` 调用原工具的完整引擎，而不是重新实现一套缩减版。当前仅支持 macOS Apple Silicon；Linux/Docker 不支持这个引擎，接口会明确报错。

支持需求文本、多文档合并、Word（DOC/DOCX）、PDF、Excel、Markdown、JSON/YAML、XMind、PNG/JPEG。Word/PDF 内嵌图片和独立截图由所选模型识别，因此模型必须支持视觉输入。单文件上限为 5 MB，总上传上限为 10 MB（包含补充和续跑文件），需求文件最多 10 个，支持分次添加和移除。执行阶段包括完整流程、需求分析、完整测试方案，以及上传结构化需求/候选 JSON 后续跑。补充确认支持文件或文本。

个人知识库支持批量导入 Markdown、TXT、XLSX、XLS，最多 10 个文件，单文件 5 MB、总量 10 MB。文件列表显示原始名称、分类、大小和导入时间，可查看文本内容或 Excel 各工作表前 100 行，并下载原文件。已有无名称元数据的文件继续使用原存储名称显示；知识文件按账户隔离。

导出包括多工作表 Excel、XMind、Markdown，以及需求分析 Word、确认模板和审计 JSON。Excel 保留原工具的全量/前端冒烟/后端冒烟/回归表，多端需求按原工具规则拆分 WEB/H5/APP 冒烟表。结果栏留空，不预填通过。正式 Excel 可预览并选择保存到项目；写入仍受项目权限校验。失败任务仅开放诊断和续跑文件，不开放正式导出。

知识库支持导入 Markdown、TXT、XLSX、XLS，按 `testcases` / `test_plans` 分类；保存和复用沿用原引擎。知识库按当前账户隔离，任务文件保存于 `data/generator/jobs`。完整图片识别缓存按账户和模型配置隔离复用，配置变化时重新识别；不缓存源图片。仅复用引擎，不复制桌面工具的设置、API Key 或原有私有知识文件。任务异步执行，可查看日志和取消，刷新页面后恢复最近任务；重启服务后保留已完成产物，中断任务标记失败并支持 JSON 续跑。页面使用 AI 设置中的主模型及可选备用模型，经短期令牌认证的本机网关转发；上游流中断或截断不会被当成成功结果。

恢复旧模型配置时必须使用原 `APP_SECRET`，否则旧 API Key 无法解密；也可以由管理员重新保存模型密钥。切勿把开发密钥覆盖成空值来绕过解密错误。

新安装默认提供千问 `qwen-vl-max` 配置，API Key 留空。管理员在 AI 设置的模型配置区填写密钥后才能生成；不自动读取桌面工具或钥匙串密钥。现有安装如明确要清理旧模型，可先停止服务，再执行 `node --env-file=.env scripts/reset-ai-default.mjs`；该脚本先备份旧加密配置到 `data/config-backups`，然后仅保留空密钥千问默认，其他业务数据不变。

AI 工作台使用页面内向下展开的选项控件，支持键盘方向键和 Esc。切换任务 Tab 保留本次会话的需求文本、选项与文件；退出登录清空。JSON 续跑文件只在续跑阶段启用；任务轮询只更新日志，不反复重绘正在输入的表单。

生成结果、运行日志、知识库采用同一工作区内的三个 Tab，内容显示在 Tab 下方。新任务自动打开运行日志，成功后从日志切到生成结果。确认文件与确认文字二选一；同时提交将被拒绝，防止原引擎重复 `--confirmed` 参数导致前一份材料被覆盖。

## 密钥安全

API Key 使用由 `APP_SECRET` 派生的 AES-256-GCM 密钥加密保存，读取配置接口只返回“已配置”状态，不会返回原始 Key。务必妥善保存 `APP_SECRET`；更换它会使历史密钥不能解密。生产环境应使用密钥管理服务替代环境变量，并限制管理员权限。
