# 验收流程

下面流程可在一套新部署环境中验证核心能力。

1. 访问首页，以 `admin / admin123` 登录，确认可进入质量工作台。
2. 在“用户与权限”查看六种预置角色；退出后以 `tester / demo123` 登录，确认无法看到“用户与权限”“AI 设置”，且直接请求用户创建接口会被拒绝。
3. 以测试主管或管理员进入“测试用例”，新建一条带前置条件、步骤、预期结果、标签的用例。
4. 进入“测试计划与执行”，选择项目和刚创建的用例，创建计划；在“执行”中提交通过、失败或阻塞结果。
5. 进入“缺陷追踪”，新建缺陷，关联项目，设置严重程度、优先级和处理人；使用“更新”推进状态到已修复、已验证或已关闭。
6. 进入“测试报告”，核对通过率、未关闭缺陷和高风险项。点击“导出 HTML 报告”；在浏览器打开该文件后，使用打印对话框的“保存为 PDF”即可归档 PDF 报告。
7. 以管理员在“AI 设置”填入有效 API Key，进入“AI 智能助手”，提交一段需求，确认能生成测试用例内容。
8. 在“账号安全”启用 TOTP；退出后再次登录，确认仅有用户名和密码不能登录，输入验证器动态码后登录成功。

## 已验证的本地接口闭环

实现阶段已对健康检查、管理员登录、项目数据读取、用例创建、测试计划创建、执行结果提交、缺陷提交、HTML 报告导出进行了本机 API 冒烟验证；同时确认测试工程师尝试创建用户会被服务端拒绝。
